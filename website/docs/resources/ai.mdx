## Cheat sheet

Package: @elik56a/react-native-pickers   (npm i @elik56a/react-native-pickers)
Pure JS, zero native code, no peer deps besides react >=18 and react-native >=0.72.
Works in Expo Go, bare RN, React Native Web. All exports are named exports from the package root.
Native apps: prefer subpaths so Metro skips unused pickers (root import bundles ~130 KB of emoji data):
  /wheel /time /date /calendar /datetime /select /list /emoji /sheet /core   e.g. '@elik56a/react-native-pickers/date'
  PickersProvider and theme/date utils live in /core. Subpaths need RN 0.79+ (Metro package exports).

Controlled: value + onChange. Uncontrolled: defaultValue. SelectPicker/SelectList/HorizontalList are controlled-only.
onChange fires on user changes only (not when value is set programmatically). Wheels fire onChange when they settle;
onValueChanging fires on every row crossing (use for haptics).

## Canonical examples

```tsx
import { useState } from 'react';
import { DatePicker, DatePickerField, DatePickerSheet, SelectPicker, TimePicker, TimePickerField, WheelPicker } from '@elik56a/react-native-pickers';
import type { DateRange } from '@elik56a/react-native-pickers';

function Examples() {
  const [size, setSize] = useState('M');
  const [time, setTime] = useState(new Date());
  const [date, setDate] = useState<Date | null>(null);
  const [range, setRange] = useState<DateRange>({ start: null, end: null });
  const [country, setCountry] = useState<string | null>(null);
  const [open, setOpen] = useState(false);

  return (
    <>
      <WheelPicker items={['S', 'M', 'L']} value={size} onChange={setSize} />
      <TimePicker value={time} onChange={setTime} minuteInterval={5} />
      <DatePicker value={date} onChange={setDate} minDate={new Date()} />
      <DatePicker mode="range" value={range} onChange={setRange} />
      <SelectPicker label="Country" options={[{ label: 'Israel', value: 'IL' }]} value={country} onChange={setCountry} />
      <DatePickerSheet visible={open} onClose={() => setOpen(false)} mode="range" value={range} onConfirm={setRange} />
      {/* In forms: a field that opens the sheet and shows the value, no open state needed */}
      <DatePickerField label="Stay" mode="range" value={range} onConfirm={setRange} placeholder="Add dates" />
      <TimePickerField label="Time" value={time} onConfirm={setTime} />
    </>
  );
}
```
