# Migrate from `react-native-star-rating-widget`

`react-native-star-rating-widget` needs `react-native-svg`. [`Rating`](../../components/rating) has no dependencies, so there's nothing else to install, and it takes any icon through `renderIcon`.

## Code changes

```diff
- import StarRating, { StarRatingDisplay } from 'react-native-star-rating-widget';
+ import { Rating } from '@elik56a/react-native-pickers';

- <StarRating rating={stars} onChange={setStars} />
+ <Rating step={0.5} value={stars} onChange={setStars} />

- <StarRatingDisplay rating={4.5} />
+ <Rating readOnly value={4.5} />
```

## Props

| star-rating-widget | React Native Pickers |
| --- | --- |
| `rating` / `onChange` | `value` / `onChange`, once on a tap or the end of a drag |
| `StarRatingDisplay` | `readOnly` |
| `maxStars` | `max` |
| `starSize` | `size` |
| `color` / `emptyColor` | `color` / `emptyColor` |
| `step="half"` (default) | `step={0.5}`; the default here is `1` |
| `step="quarter"` | `step={0.25}` |
| `enableSwiping` | always on: tap or drag |
| `onRatingStart` / `onRatingEnd` | `onChange` fires once, when the drag ends |
| `StarIconComponent` | `renderIcon={({ index, filled, color, size }) => …}` |
| `starStyle` / `starContainerStyle` | `styles={{ item }}` / `styles={{ container }}` |
| `accessibilityLabel` | `accessibilityLabel`, and `formatValue` for the value |
| `animationConfig` | — |

Mind the default step: half stars here need `step={0.5}`.
