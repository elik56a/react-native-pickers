# Migrate from `@react-native-segmented-control/segmented-control`

`@react-native-segmented-control/segmented-control` uses native code on iOS, so it doesn't run in Expo Go there, and on Android and the web it imitates the iOS 13 control. [`HorizontalList`](../../components/horizontal-list) has no native code, so it runs in Expo Go and on the web, follows the iOS, Material and web designs, and scrolls sideways as chips when the options don't fit.

## Code changes

```diff
- import SegmentedControl from '@react-native-segmented-control/segmented-control';
+ import { HorizontalList } from '@elik56a/react-native-pickers';

- <SegmentedControl
-   values={['Day', 'Week', 'Month']}
-   selectedIndex={index}
-   onChange={(e) => setIndex(e.nativeEvent.selectedSegmentIndex)}
- />
+ <HorizontalList
+   items={[{ label: 'Day', value: 'day' }, { label: 'Week', value: 'week' }, { label: 'Month', value: 'month' }]}
+   value={view}
+   onChange={setView}
+ />
```

## Props

| segmented-control | React Native Pickers |
| --- | --- |
| `values` (strings) | `items` (`{ label, value, disabled?, icon? }`) |
| `selectedIndex` | `value` (the item's value, not its index) |
| `onChange(event)` / `onValueChange(label)` | `onChange(value, item)` |
| `enabled={false}` | `disabled: true` on each item |
| `tintColor` / `backgroundColor` | `theme={{ colors: { primary, surface } }}` or `styles={{ thumb, container }}` |
| — | scrolls sideways when the items don't fit, `variant="chips"`, `renderItem`, works on the web |
