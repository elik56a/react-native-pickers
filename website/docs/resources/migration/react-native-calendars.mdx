# Migrate from `react-native-calendars`

With `react-native-calendars`, you build a range or a multiple selection yourself by marking each day in `markedDates`, and the package pulls in `xdate`, `lodash` and `recyclerlistview`. [`DatePicker`](../../components/date-picker) selects ranges and multiple dates itself, names months and days through `Intl`, follows the iOS, Material and web designs, and has no dependencies.

## Code changes

```diff
- <Calendar
-   current="2026-10-01"
-   minDate="2026-10-05"
-   onDayPress={(day) => setSelected(day.dateString)}
-   markedDates={{ [selected]: { selected: true }, '2026-10-22': { marked: true, dotColor: 'green' } }}
-   firstDay={1}
- />
+ <DatePicker
+   initialMonth={new Date(2026, 9, 1)}
+   minDate={new Date(2026, 9, 5)}
+   value={selected}
+   onChange={setSelected}
+   markedDates={{ '2026-10-22': { dots: ['green'] } }}
+   firstDayOfWeek={1}
+ />
```

## Props

| react-native-calendars | React Native Pickers |
| --- | --- |
| `current` (string) | `initialMonth` (`Date`) |
| `minDate` / `maxDate` (strings) | `minDate` / `maxDate` (`Date`) |
| `onDayPress(day)` | `onChange(date)`; selection is managed for you |
| `markedDates[k].selected` | `value` (no manual marking) |
| `markingType="period"` + manual start/end marking | `mode="range"` |
| `markedDates[k].marked` + `dotColor` | `markedDates[k].dots: [color]` |
| `markingType="multi-dot"` `dots: [{ color }]` | `dots: ['#hex', …]` (max 3) |
| `markedDates[k].disabled` / `disableTouchEvent` | `markedDates[k].disabled` or `isDateDisabled` |
| `firstDay` | `firstDayOfWeek` |
| `onMonthChange` | `onMonthChange(month: Date)` |
| `hideExtraDays` | `showOutsideDays={false}` |
| `enableSwipeMonths` | `enableSwipe` (on by default) |
| `dayComponent` | `renderDay(state, theme)` |
| `renderArrow(direction)` | `renderArrow(direction, disabled)` |
| `theme={{ selectedDayBackgroundColor, todayTextColor, … }}` | `theme={{ colors: { primary, … } }}` + `styles` slots |
| `LocaleConfig` | `locale="fr-FR"` (names from `Intl`) |

## ExpandableCalendar

Its `ExpandableCalendar` needs a `CalendarProvider` around it to share the date with an `AgendaList`. Here the date is plain state: the calendar sets it, the [`Agenda`](../../components/agenda) scrolls to it, and the agenda sets it back as the user scrolls.

```diff
- <CalendarProvider date={selected} onDateChanged={setSelected}>
-   <ExpandableCalendar firstDay={1} markedDates={marked} />
-   <AgendaList sections={sections} renderItem={renderItem} />
- </CalendarProvider>
+ <ExpandableCalendar value={selected} onChange={setSelected} firstDayOfWeek={1} markedDates={marks} />
+ <Agenda events={events} selectedDate={selected} onVisibleDateChange={setSelected} />
```

| react-native-calendars | React Native Pickers |
| --- | --- |
| `CalendarProvider date` / `onDateChanged` | `value` / `onChange` on [`ExpandableCalendar`](../../components/expandable-calendar) |
| `initialPosition="open"` | `defaultExpanded` |
| `onCalendarToggled(open)` | `onExpandedChange(expanded)` |
| `disablePan` | `enableSwipe={false}` |
| `WeekCalendar` | [`WeekStrip`](../../components/week-strip) |

## Agenda, AgendaList and Timeline

Its `AgendaList` takes `sections` you group by day yourself, and its `Timeline` takes events keyed by date string. [`Agenda`](../../components/agenda) and [`Timeline`](../../components/timeline) take one flat array of events with `Date`s, group and lay them out themselves, and follow the iOS, Material and web designs.

```diff
- <Timeline
-   events={eventsByDate[date]}
-   date={date}
-   onEventPress={openEvent}
-   onBackgroundLongPress={(timeString, time) => addEvent(time)}
-   start={7}
-   end={20}
- />
+ <Timeline events={events} date={day} onEventPress={openEvent} onSlotPress={({ start, end }) => addEvent(start, end)} startHour={7} endHour={20} />
```

| react-native-calendars | React Native Pickers |
| --- | --- |
| `AgendaList sections` | `Agenda events` (grouped by day for you) |
| `Agenda items` + `renderItem` | `Agenda events` + `renderEvent` |
| `renderEmptyDate` | `showEmptyDays` + `labels.noEvents` |
| `onDayChange` | `onVisibleDateChange(date)` |
| event `{ start: 'YYYY-MM-DD HH:mm', end, title, summary, color }` | `{ id, start: Date, end: Date, title, subtitle, color, allDay }` |
| `Timeline start` / `end` | `startHour` / `endHour` |
| `onBackgroundLongPress` | `onSlotPress({ start, end })` (a tap) |
| `scrollToFirst` / `initialTime` | `initialScrollHour` (opens at now, else the first event) |
| `showNowIndicator` | `showNowIndicator` (on by default) |
| `format24h` | `format="24h"` |
| `numberOfDays` | `numberOfDays` (1 to 7) |
| `renderEvent` | `renderEvent(info)` |
| `TimelineList` | `Timeline` with `date` / `onDateChange` (swipe pages by days) |
