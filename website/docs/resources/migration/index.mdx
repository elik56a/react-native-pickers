# Migration

Prop-by-prop guides from popular packages. Most migrations are a rename plus switching callbacks to `(value) => …`.

Compared with native pickers, your users keep a native look: the iOS design on iOS and Material Design on Android, by default. Set `design="ios"` on `PickersProvider` if you'd rather show the same look everywhere. See [Designs](../../guides/designs.mdx).
