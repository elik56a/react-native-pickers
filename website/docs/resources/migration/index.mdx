# Migration

Prop-by-prop guides from popular packages. Most migrations are a rename plus switching callbacks to `(value) => …`.

Compared with native pickers, your users keep a native look: the iOS design on iOS, Material Design on Android and the web design in the browser, by default. Set `design="ios"` on `PickersProvider` if you'd rather show the same look everywhere. See [Designs](../../guides/designs.mdx).
