# Migrate from `@ptomasroos/react-native-multi-slider`

`@ptomasroos/react-native-multi-slider` hasn't had a release since March 2020. [`Slider`](../../components/slider) covers a single value and a range in one component, with no native code or Reanimated, a screen-reader label on each thumb (`thumbLabels`) and arrow keys on the web.

## Code changes

```diff
- import MultiSlider from '@ptomasroos/react-native-multi-slider';
+ import { Slider } from '@elik56a/react-native-pickers';

- <MultiSlider
-   values={price}
-   min={0}
-   max={500}
-   step={10}
-   sliderLength={280}
-   onValuesChangeFinish={setPrice}
-   enableLabel
- />
+ <Slider
+   range
+   value={price}
+   min={0}
+   max={500}
+   step={10}
+   onChange={setPrice}
+   valueLabel="always"
+ />
```

## Props

| multi-slider | React Native Pickers |
| --- | --- |
| `values` (`[a]` or `[a, b]`) | `value`: a number, or `[start, end]` with `range` |
| `min` / `max` / `step` | `min` / `max` / `step` |
| `onValuesChange` | `onValueChanging` |
| `onValuesChangeFinish` | `onChange` |
| `onValuesChangeStart` | — |
| `sliderLength` | not needed: the slider fills its container, or set `style={{ width }}` |
| `optionsArray` / `snapped` | `marks={[…]}` with `snapToMarks` |
| `enableLabel` / `customLabel` | `valueLabel="always"` or `"drag"`, with `formatValue` |
| `valuePrefix` / `valueSuffix` | ``formatValue={(v) => `$${v}`}`` |
| `allowOverlap` / `minMarkerOverlapDistance` | the thumbs can meet but not cross |
| `selectedStyle` / `unselectedStyle` | `styles={{ activeTrack, track }}` |
| `markerStyle` / `customMarker` | `styles={{ thumb }}` |
| `enabledOne` / `enabledTwo` | `disabled` for the whole slider |
| `vertical` | — |
