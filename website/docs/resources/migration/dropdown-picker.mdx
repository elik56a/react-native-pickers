# Migrate from `react-native-dropdown-picker`

`react-native-dropdown-picker` hasn't had a release since March 2023.

`SelectPicker` keeps its own open state, so `open`, `setOpen` and `setItems` go away, and `onChange` gets the new value rather than an updater. It opens as a dropdown on the web and a bottom sheet on phones, where a dropdown is cramped; set `presentation="dropdown"` to keep the dropdown everywhere.

## Code changes

```diff
- import DropDownPicker from 'react-native-dropdown-picker';
+ import { SelectPicker } from '@elik56a/react-native-pickers';

- const [open, setOpen] = useState(false);
  const [value, setValue] = useState(null);
- const [items, setItems] = useState([
-   { label: 'Apple', value: 'apple' },
-   { label: 'Banana', value: 'banana' },
- ]);
-
- <DropDownPicker open={open} value={value} items={items} setOpen={setOpen} setValue={setValue} setItems={setItems} />
+ <SelectPicker
+   options={[{ label: 'Apple', value: 'apple' }, { label: 'Banana', value: 'banana' }]}
+   value={value}
+   onChange={setValue}
+ />
```

## Props

| react-native-dropdown-picker | React Native Pickers |
| --- | --- |
| `items` + `setItems` | `options` (adds `description`, `icon`, `group`, `keywords`) |
| `value` + `setValue` | `value` + `onChange(value, option)` |
| `open` + `setOpen` | not needed; `onOpen` / `onClose` if you want to know |
| `onChangeValue` | `onChange` |
| `multiple` | `multiple` (selected items show as removable chips) |
| `min` / `max` | `maxSelected`; check a minimum in your form |
| `searchable` | `searchable` (on by default past 8 options) |
| `searchPlaceholder` | `searchPlaceholder` |
| `onChangeSearchText` + `disableLocalSearch` + `loading` | `onSearchChange` + `loading`, or `loadOptions(query)` that returns a promise |
| `placeholder` | `placeholder` |
| `disabled` | `disabled` |
| `listMode="MODAL"` | `presentation="modal"` |
| `listMode="FLATLIST"` / `"SCROLLVIEW"` | `presentation="dropdown"` |
| `renderListItem` | `renderOption({ option, selected, disabled, theme })` |
| `addCustomItem` | `onCreate(text)`: add the option to `options` and return it to select it ([create new options](../../components/select-picker#create-new-options)) |

See [SelectPicker](../../components/select-picker) for groups, icons and render props, and [server search](../../recipes/server-search).
