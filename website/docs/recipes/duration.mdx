# Duration & timer picker

`TimePicker` picks a time of day. For a **length of time** (timer, workout, cooking), use `MultiWheelPicker` with unit labels. Here it opens from a [`PickerField`](../components/picker-fields#your-own-sheet-pickerfield), so it fits a form on every platform: the field and the sheet's buttons follow the [design](../guides/designs), it opens in a bottom sheet on iOS and Android and in a dropdown under the field on the web, and nothing changes until the user confirms.

```tsx live
import { useState } from 'react';
import { StyleSheet, Text } from 'react-native';
import {
  MultiWheelPicker,
  PickerField,
  PickerSheet,
  useDraft,
  usePickerTheme,
} from '@elik56a/react-native-pickers';

type Duration = { h: number; m: number; s: number };

const range = (n: number) => Array.from({ length: n }, (_, i) => i);
const HOURS = range(24);
const SIXTY = range(60);
const UNITS = ['hours', 'min', 'sec'];

const format = ({ h, m, s }: Duration) =>
  [h && `${h} h`, m && `${m} min`, s && `${s} s`].filter(Boolean).join(' ');

function Unit({ children }: { children?: string }) {
  const { colors } = usePickerTheme();
  return <Text style={[styles.unit, { color: colors.textSecondary }]}>{children}</Text>;
}

function DurationSheet({
  visible,
  onClose,
  value,
  onSave,
}: {
  visible: boolean;
  onClose: () => void;
  value: Duration;
  onSave: (d: Duration) => void;
}) {
  const [draft, setDraft] = useDraft(value, visible);
  return (
    <PickerSheet
      visible={visible}
      onClose={onClose}
      title="Timer"
      confirmDisabled={!format(draft)}
      onConfirm={() => {
        onSave(draft);
        onClose();
      }}
    >
      <MultiWheelPicker
        separator={(left) => <Unit>{UNITS[left]}</Unit>}
        columns={[
          {
            key: 'h',
            items: HOURS,
            value: draft.h,
            onChange: (h) => setDraft({ ...draft, h }),
            accessibilityLabel: 'Hours',
            textAlign: 'right',
          },
          {
            key: 'm',
            items: SIXTY,
            value: draft.m,
            onChange: (m) => setDraft({ ...draft, m }),
            loop: true,
            accessibilityLabel: 'Minutes',
            textAlign: 'right',
          },
          {
            key: 's',
            items: SIXTY,
            value: draft.s,
            onChange: (s) => setDraft({ ...draft, s }),
            loop: true,
            accessibilityLabel: 'Seconds',
            textAlign: 'right',
          },
        ]}
      />
    </PickerSheet>
  );
}

export default function Timer() {
  const [duration, setDuration] = useState<Duration>({ h: 0, m: 25, s: 0 });
  return (
    <PickerField label="Timer" placeholder="Pick a duration" displayValue={format(duration)}>
      {(sheet) => <DurationSheet {...sheet} value={duration} onSave={setDuration} />}
    </PickerField>
  );
}

const styles = StyleSheet.create({
  unit: { fontSize: 14, fontWeight: '600', width: 44 },
});
```

## How it works

- **`PickerField` + `PickerSheet`.** The field owns the open state and hands `{ visible, onClose }` to the sheet. A `PickerSheet` inside a field follows its `presentation`, so `'auto'` is a dropdown on the web and a bottom sheet on native.
- **`useDraft`** copies the duration into a draft each time the sheet opens. The wheels change only the draft; **Done** (**OK** in Material) saves it, and closing any other way discards it. **Done** stays disabled at zero.
- **Unit labels.** The `separator` function gets the index of the column on its **left**, so each gap shows that column's unit.
- **Inline**, without the field, render the `MultiWheelPicker` on its own and keep `h`, `m` and `s` in state.

Wheels look the same in every design, so the duration looks alike on each platform; the field, the sheet and the buttons around it are what change.
