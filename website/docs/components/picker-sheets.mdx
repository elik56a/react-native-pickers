# Picker sheets

Every React Native picker in this library is also available inside a [`BottomSheet`](./bottom-sheet) with **Cancel / Done**: in the header beside the title on iOS, under the content in Material (as **OK**) and on the web, per the [design](../guides/designs). They all share the same "chrome" props and the same draft behaviour.

This page covers `DatePickerSheet`, `TimePickerSheet`, `WheelPickerSheet`, `EmojiPickerSheet` and the `PickerSheet` building block. The other sheets are on their picker's page: [`DateTimePickerSheet`](./date-time-picker#in-a-sheet), [`TimeRangePickerSheet`](./time-range-picker#in-a-sheet-or-a-field), [`DurationPickerSheet`](./duration-picker#in-a-sheet), [`MonthPickerSheet`](./month-picker#in-a-sheet) and [`ColorPickerSheet`](./color-picker#in-a-sheet).

:::tip Opening a sheet from a form field?
You don't need your own button and `visible` state. [Picker fields](./picker-fields) (`DatePickerField`, `TimePickerField`, `TimeRangePickerField`, `DateTimePickerField`, `DurationPickerField`, `MonthPickerField`, `ColorPickerField`, `WheelPickerField`, `EmojiPickerField`) take the same props without `visible`/`onClose`, render a field that opens the sheet, and show the confirmed value.
:::

## Inline, bottom sheet or modal

Every picker can be shown three ways:

- **Inline:** the plain component (`WheelPicker`, `TimePicker`, `DatePicker`, `SelectList`, `EmojiPicker`) renders in place.
- **Bottom sheet:** slides up from the bottom and can be dragged down to dismiss.
- **Modal:** a centered dialog.

Each sheet can also open from a [field](./picker-fields) that shows the picked value.

The sheets take `presentation`: `'auto'` (default), `'bottomSheet'` or `'modal'`. `auto` is a modal on web windows wider than the sheet, where a bottom sheet would look cut off, and a bottom sheet on phones and native.

```tsx
<TimePickerSheet presentation="modal" visible={open} onClose={close} value={time} onConfirm={setTime} />
```

[`SelectPicker`](./select-picker#presentation) and the [fields](./picker-fields#dropdown-bottom-sheet-modal-or-inline) also support `'dropdown'`, which opens under the field, and `'inline'`, which expands under it. There, `'auto'` opens a dropdown on the web.

```tsx
import { DatePickerSheet, TimePickerSheet, WheelPickerSheet, EmojiPickerSheet, PickerSheet, useDraft } from '@elik56a/react-native-pickers';
```

## How drafts work

1. When the sheet **opens**, it copies `value` into a draft.
2. The picker inside edits only the draft.
3. **Done** calls `onConfirm(draft)` and then `onClose()`.
4. **Cancel**, a backdrop tap, a swipe down or Android back calls only `onClose()`, and the draft is thrown away.

Your state changes only when the user confirms, which is how native iOS / Android pickers behave. The exception is a [field](./picker-fields#dropdown-bottom-sheet-modal-or-inline) set to `presentation="inline"`: it has no **Done**, so each change is confirmed right away.

## DatePickerSheet

A calendar (single, range, multiple or ranges) or a date wheel in a sheet. Props: [DatePickerSheet props](#datepickersheet-props).

```tsx live
import { useState } from 'react';
import { Pressable, Text, View } from 'react-native';
import { DatePickerSheet, formatDate } from '@elik56a/react-native-pickers';
import type { DateRange } from '@elik56a/react-native-pickers';

function Field({
  label,
  value,
  onPress,
}: {
  label: string;
  value: string;
  onPress: () => void;
}) {
  return (
    <Pressable
      onPress={onPress}
      style={{
        borderWidth: 1,
        borderColor: '#E8E4DC',
        borderRadius: 12,
        padding: 14,
      }}
    >
      <Text style={{ fontSize: 12, color: '#6E685E' }}>{label}</Text>
      <Text style={{ fontSize: 16, marginTop: 2 }}>{value}</Text>
    </Pressable>
  );
}

export default function Example() {
  const [sheet, setSheet] = useState<'day' | 'range' | 'birthday' | null>(null);
  const [day, setDay] = useState<Date | null>(null);
  const [range, setRange] = useState<DateRange>({ start: null, end: null });
  const [birthday, setBirthday] = useState(new Date(1995, 6, 12));
  const close = () => setSheet(null);
  return (
    <View style={{ gap: 10 }}>
      <Field
        label="Delivery date"
        value={day ? formatDate(day) : 'Choose…'}
        onPress={() => setSheet('day')}
      />
      <Field
        label="Trip"
        value={
          range.start && range.end
            ? `${formatDate(range.start)} → ${formatDate(range.end)}`
            : 'Choose…'
        }
        onPress={() => setSheet('range')}
      />
      <Field
        label="Birthday"
        value={formatDate(birthday)}
        onPress={() => setSheet('birthday')}
      />

      <DatePickerSheet
        visible={sheet === 'day'}
        onClose={close}
        title="Delivery"
        value={day}
        onConfirm={setDay}
        minDate={new Date()}
        confirmOnSelect
      />
      <DatePickerSheet
        visible={sheet === 'range'}
        onClose={close}
        title="Trip dates"
        mode="range"
        value={range}
        onConfirm={setRange}
        minDate={new Date()}
      />
      <DatePickerSheet
        visible={sheet === 'birthday'}
        onClose={close}
        title="Birthday"
        display="wheel"
        value={birthday}
        onConfirm={setBirthday}
        maxDate={new Date()}
      />
    </View>
  );
}
```

### Behaviour

- **Done is disabled** until the selection is complete: a date in single mode, both `start` and `end` in range mode, no half-picked range in ranges mode. Multiple and ranges modes can confirm an empty array.
- **`confirmOnSelect`** (single + calendar only) hides Done and confirms as soon as a day is tapped.
- **`display="wheel"`** shows a [DateWheelPicker](./date-wheel-picker) (single mode). The draft starts at `value` or today. `locale`, `minDate` and `maxDate` are forwarded; pass other wheel props via `wheelProps`.
- In the Material design, the picked date or range shows in large type above the calendar.

## TimePickerSheet

A [TimePicker](./time-picker) in a sheet. Props: [TimePickerSheet props](#timepickersheet-props).

```tsx live
import { useState } from 'react';
import { Pressable, Text } from 'react-native';
import { TimePickerSheet } from '@elik56a/react-native-pickers';

export default function Example() {
  const [open, setOpen] = useState(false);
  const [time, setTime] = useState(new Date(2026, 0, 1, 7, 30));
  return (
    <>
      <Pressable
        onPress={() => setOpen(true)}
        style={{ alignItems: 'center', padding: 12 }}
      >
        <Text style={{ fontSize: 48, fontWeight: '200' }}>
          {time.toLocaleTimeString([], { hour: 'numeric', minute: '2-digit' })}
        </Text>
        <Text style={{ color: '#C8460D' }}>Change</Text>
      </Pressable>
      <TimePickerSheet
        visible={open}
        onClose={() => setOpen(false)}
        title="Wake up"
        value={time}
        onConfirm={setTime}
        minuteInterval={5}
      />
    </>
  );
}
```

## WheelPickerSheet

A [WheelPicker](./wheel-picker) in a sheet. Props: [WheelPickerSheet props](#wheelpickersheet-props).

```tsx live
import { useState } from 'react';
import { Pressable, Text } from 'react-native';
import { WheelPickerSheet } from '@elik56a/react-native-pickers';

const guests = Array.from({ length: 12 }, (_, i) => ({
  label: `${i + 1} guest${i ? 's' : ''}`,
  value: i + 1,
}));

export default function Example() {
  const [open, setOpen] = useState(false);
  const [count, setCount] = useState(2);
  return (
    <>
      <Pressable
        onPress={() => setOpen(true)}
        style={{
          borderWidth: 1,
          borderColor: '#E8E4DC',
          borderRadius: 12,
          padding: 14,
        }}
      >
        <Text>👥 {guests[count - 1].label}</Text>
      </Pressable>
      <WheelPickerSheet
        visible={open}
        onClose={() => setOpen(false)}
        title="Guests"
        items={guests}
        value={count}
        onConfirm={setCount}
      />
    </>
  );
}
```

## EmojiPickerSheet

No Done button: each pick calls `onSelect`, and the sheet closes unless `closeOnSelect={false}`. Props: [EmojiPickerSheet props](#emojipickersheet-props).

```tsx live
import { useState } from 'react';
import { Pressable, Text, View } from 'react-native';
import { EmojiPickerSheet } from '@elik56a/react-native-pickers';

export default function Example() {
  const [open, setOpen] = useState(false);
  const [reactions, setReactions] = useState(['👍', '🎉']);
  return (
    <View style={{ flexDirection: 'row', gap: 8, flexWrap: 'wrap' }}>
      {reactions.map((r, i) => (
        <Text
          key={i}
          style={{
            fontSize: 22,
            backgroundColor: '#F4F2EE',
            borderRadius: 999,
            paddingHorizontal: 10,
            paddingVertical: 4,
          }}
        >
          {r}
        </Text>
      ))}
      <Pressable
        onPress={() => setOpen(true)}
        style={{
          borderRadius: 999,
          borderWidth: 1,
          borderColor: '#E8E4DC',
          paddingHorizontal: 12,
          justifyContent: 'center',
        }}
      >
        <Text>＋</Text>
      </Pressable>
      <EmojiPickerSheet
        visible={open}
        onClose={() => setOpen(false)}
        title="React"
        onSelect={(e) => setReactions((r) => [...r, e])}
      />
    </View>
  );
}
```

## PickerSheet

The building block: a `BottomSheet` with Cancel and, when you pass `onConfirm`, Done, placed where the design puts them. Use it to build sheets for your own pickers. Props: [PickerSheet props](#pickersheet-props).

```tsx live
import { useState } from 'react';
import { Pressable, Text, Switch, View } from 'react-native';
import { PickerSheet, useDraft } from '@elik56a/react-native-pickers';

type Prefs = { push: boolean; email: boolean };

export default function Example() {
  const [open, setOpen] = useState(false);
  const [prefs, setPrefs] = useState<Prefs>({ push: true, email: false });
  const [draft, setDraft] = useDraft(prefs, open);
  return (
    <>
      <Pressable
        onPress={() => setOpen(true)}
        style={{ padding: 14, borderRadius: 12, backgroundColor: '#F4F2EE' }}
      >
        <Text>
          Notifications:{' '}
          {[prefs.push && 'push', prefs.email && 'email']
            .filter(Boolean)
            .join(' + ') || 'off'}
        </Text>
      </Pressable>
      <PickerSheet
        visible={open}
        onClose={() => setOpen(false)}
        title="Notifications"
        confirmLabel="Save"
        onConfirm={() => {
          setPrefs(draft);
          setOpen(false);
        }}
      >
        <View style={{ padding: 16, gap: 16 }}>
          {(['push', 'email'] as const).map((k) => (
            <View
              key={k}
              style={{
                flexDirection: 'row',
                justifyContent: 'space-between',
                alignItems: 'center',
              }}
            >
              <Text style={{ fontSize: 16, textTransform: 'capitalize' }}>
                {k}
              </Text>
              <Switch
                value={draft[k]}
                onValueChange={(v) => setDraft({ ...draft, [k]: v })}
              />
            </View>
          ))}
        </View>
      </PickerSheet>
    </>
  );
}
```

## `useDraft`

```ts
function useDraft<V>(
  value: V,
  visible: boolean,
  options?: { resetKey?: unknown; commit?: (v: V) => void }
): [draft: V, setDraft: (v: V) => void];
```

Returns a draft copy of `value` that **resets to `value` each time `visible` turns true** (and whenever `resetKey` changes). It's the hook the built-in sheets use; use it for your own `PickerSheet`s as shown above.

Inside a [`PickerField`](./picker-fields#dropdown-bottom-sheet-modal-or-inline) set to `presentation="inline"` there's no **Done** button, so `setDraft` also calls `commit` with each change. Pass your save function there to support inline: `useDraft(prefs, visible, { commit: onSave })`.

## Props

### Shared props

All sheets accept these (`SheetChromeProps`):

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `visible` | `boolean` | **required** | Show / hide. |
| `onClose` | `() => void` | **required** | Set `visible` to `false` here. |
| `title` | `ReactNode` | — | Header title. |
| `confirmLabel` | `string` | `'Done'` · `'OK'` Material | Confirm button text. |
| `cancelLabel` | `string` | `'Cancel'` | Cancel button text. |
| `showCancel` | `boolean` | `true` (`false` for emoji) | Show the Cancel button. |
| `presentation` | `'auto' \| 'bottomSheet' \| 'modal'` | `'auto'` | Bottom sheet or centered modal. `auto`: modal on wide web windows, bottom sheet elsewhere. |
| `sheetProps` | `Partial<BottomSheetProps>` | — | Passed to the [BottomSheet](./bottom-sheet#props) (`height`, `bottomInset`, `styles`, `enableSwipeToClose`…). |
| `theme` | `DeepPartial<PickerTheme>` | — | Theme for the sheet and the picker. |
| `design` | `'ios' \| 'material' \| 'web'` | from `PickersProvider` | The look to follow, over the provider's: [iOS, Material or web](../guides/designs). |

### DatePickerSheet props

Shared props, plus every [calendar prop](./date-picker#calendar) (`minDate`, `maxDate`, `isDateDisabled`, `markedDates`, `locale`, `firstDayOfWeek`, `styles`, `renderDay`…), plus:

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `mode` | `'single' \| 'range' \| 'multiple' \| 'ranges'` | `'single'` | Selection mode. |
| `value` | `Date \| null` · `DateRange` · `Date[]` · `DateRange[]` | — | Current committed value; copied into the draft on open. |
| `onConfirm` | `(date: Date)` · `(range: DateRange)` · `(dates: Date[])` · `(ranges: DateRange[])` `=> void` | **required** | Called with the draft on Done. |
| `minRangeDays` / `maxRangeDays` | `number` | — | Range and ranges modes. |
| `presets` | `DateRangePreset[]` | — | Range mode: chips that pick a whole range, such as [`getRangePresets()`](./date-range-picker#presets). |
| `presetsProps` | `RangePresetsListProps` | — | Range mode: [`HorizontalList`](./horizontal-list#props) props for the presets row. |
| `maxSelections` | `number` | — | Multiple mode. |
| `maxRanges` | `number` | — | Ranges mode. |
| `display` | `'calendar' \| 'wheel'` | `'calendar'` | Wheel is single mode only. |
| `wheelProps` | `Partial<DateWheelPickerProps>` | — | Extra props for the wheel. |
| `confirmOnSelect` | `boolean` | `false` | Single calendar: confirm on tap, no Done button. |

### TimePickerSheet props

Shared props, every [TimePicker prop](./time-picker#props) except `value`/`defaultValue`/`onChange`, plus:

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `Date` | now | Copied into the draft on open. |
| `onConfirm` | `(date: Date) => void` | **required** | Called with the draft on Done. |

### WheelPickerSheet props

Shared props, every [WheelPicker prop](./wheel-picker#props) except `value`/`defaultValue`/`onChange`, plus:

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `T` | first item | Copied into the draft on open. |
| `onConfirm` | `(value: T) => void` | **required** | Called with the draft on Done. |

### EmojiPickerSheet props

Shared props, every [EmojiPicker prop](./emoji-picker#props), plus:

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `closeOnSelect` | `boolean` | `true` | Close after a pick. |
| `height` | `number` | `420` | Picker height inside the sheet. |
| `showCancel` | `boolean` | `false` | Show a Cancel button. |

### PickerSheet props

Shared props, plus:

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `ReactNode` | **required** | Sheet content. |
| `onConfirm` | `() => void` | — | Shows the confirm button. **You** close the sheet (call `onClose` / set `visible`). |
| `confirmDisabled` | `boolean` | `false` | Disable the confirm button. |
| `presentation` | `'auto' \| 'bottomSheet' \| 'modal' \| 'dropdown' \| 'inline'` | the field's, else `'auto'` | Inside a [field](./picker-fields#your-own-sheet-pickerfield), it follows the field's presentation. |
