# SelectPicker

`SelectPicker` is a React Native form field that opens a searchable list: in a bottom sheet on phones, a dropdown under the field on the web, or a centered modal (`presentation`). Single or multiple selection, with groups, icons, descriptions, chips, a clear button and [search on your server](../recipes/server-search). It follows the [iOS, Material or web design](../guides/designs): a ✓ or radios, rounded or edge-to-edge rows.

```tsx
import { SelectPicker } from '@elik56a/react-native-pickers';
```

```tsx live
import { useState } from 'react';
import { SelectPicker } from '@elik56a/react-native-pickers';

const fruits = [
  'Apple',
  'Banana',
  'Cherry',
  'Mango',
  'Orange',
  'Peach',
  'Pear',
  'Plum',
  'Strawberry',
  'Watermelon',
].map((f) => ({
  label: f,
  value: f.toLowerCase(),
}));

export default function Example() {
  const [fruit, setFruit] = useState<string | null>(null);
  return (
    <SelectPicker
      label="Favourite fruit"
      placeholder="Pick one"
      options={fruits}
      value={fruit}
      onChange={setFruit}
    />
  );
}
```

:::caution Always controlled
`SelectPicker` doesn't store the selection itself. Pass `value` and update it from `onChange`.
:::

## Options

```ts
interface SelectOption<T> {
  label: string;           // row text, and what search matches first
  value: T;                // any type; compared with isEqual (default Object.is)
  description?: string;    // second line, also searchable
  icon?: React.ReactNode;  // leading element: flag, avatar, icon
  group?: string;          // section header
  disabled?: boolean;
  keywords?: string[];     // extra search terms, e.g. other languages or synonyms
}
```

```tsx live
import { useState } from 'react';
import { Text } from 'react-native';
import { SelectPicker } from '@elik56a/react-native-pickers';

const countries = [
  {
    label: 'Israel',
    value: 'IL',
    icon: <Text>🇮🇱</Text>,
    group: 'Middle East',
    keywords: ['ישראל'],
  },
  { label: 'Jordan', value: 'JO', icon: <Text>🇯🇴</Text>, group: 'Middle East' },
  {
    label: 'France',
    value: 'FR',
    icon: <Text>🇫🇷</Text>,
    group: 'Europe',
    description: 'République française',
  },
  {
    label: 'Germany',
    value: 'DE',
    icon: <Text>🇩🇪</Text>,
    group: 'Europe',
    keywords: ['deutschland'],
  },
  {
    label: 'Spain',
    value: 'ES',
    icon: <Text>🇪🇸</Text>,
    group: 'Europe',
    disabled: true,
    description: 'Not shipping yet',
  },
  {
    label: 'Japan',
    value: 'JP',
    icon: <Text>🇯🇵</Text>,
    group: 'Asia',
    keywords: ['nippon'],
  },
];

export default function Example() {
  const [country, setCountry] = useState<string | null>('FR');
  return (
    <SelectPicker
      label="Ship to"
      options={countries}
      value={country}
      onChange={setCountry}
      searchable
    />
  );
}
```

Groups appear in the order their first option appears in `options`. Options without a `group` are listed together without a header.

## Multiple selection

`multiple` switches `value` to an array and `onChange` to `(values, options)`. The sheet gets checkboxes and a **Done** button, and the field shows removable **chips** (tap a chip to remove it). `maxSelected` caps the selection; once reached, the remaining options are disabled.

```tsx live
import { useState } from 'react';
import { SelectPicker } from '@elik56a/react-native-pickers';

const skills = [
  'React',
  'React Native',
  'TypeScript',
  'Expo',
  'Node.js',
  'GraphQL',
  'Swift',
  'Kotlin',
].map((s) => ({ label: s, value: s }));

export default function Example() {
  const [picked, setPicked] = useState<string[]>([
    'React Native',
    'TypeScript',
  ]);
  return (
    <SelectPicker
      multiple
      label="Skills (max 4)"
      placeholder="Add skills"
      options={skills}
      value={picked}
      onChange={setPicked}
      maxSelected={4}
      clearable
    />
  );
}
```

Set `chips={false}` to show a comma-separated list instead of chips.

## Search

As a **dropdown** (the default on the web), the user types right in the field to filter the options; `searchable={false}` keeps the field read-only. In a **sheet**, the search field appears automatically when there are **more than 8 options**; force it with `searchable` / `searchable={false}`. The default filter:

- matches `label`, `description` and `keywords`
- is case-insensitive and **accent-insensitive** (`creme` finds `Crème`), and ignores Hebrew niqqud
- splits the query on spaces and requires **every** word to match (`new yo` finds `New York`)

Provide `filterOption` for your own logic, for example matching only from the start of the label:

```tsx
<SelectPicker
  options={options}
  value={value}
  onChange={setValue}
  filterOption={(option, query) => option.label.toLowerCase().startsWith(query.toLowerCase())}
/>
```

The default is exported as `defaultFilter`, so you can extend it:

```tsx
import { defaultFilter } from '@elik56a/react-native-pickers';

filterOption={(o, q) => defaultFilter(o, q) || o.value === q.toUpperCase()}
```

## Create new options

`onCreate` lets the user add what they typed: while no option's label matches the search, ignoring case and accents, a last row offers **Add "…"**. It gets the trimmed text; add the new option to `options` and return it to select it, as for tags, recipients or your own categories. The search clears, so the next one can be typed straight away.

```tsx live
import { useState } from 'react';
import { SelectPicker } from '@elik56a/react-native-pickers';
import type { SelectOption } from '@elik56a/react-native-pickers';

const initialTags: SelectOption<string>[] = ['Bug', 'Design', 'Docs'].map((label) => ({
  label,
  value: label.toLowerCase(),
}));

export default function Example() {
  const [tags, setTags] = useState(initialTags);
  const [selected, setSelected] = useState<string[]>(['bug']);
  return (
    <SelectPicker
      label="Tags"
      multiple
      searchable
      options={tags}
      value={selected}
      onChange={setSelected}
      onCreate={(text) => {
        const tag = { label: text, value: text.toLowerCase() };
        setTags((current) => [...current, tag]);
        return tag;
      }}
    />
  );
}
```

`createLabel` words the row, e.g. ``createLabel={(text) => `Create tag "${text}"`}``. Return nothing from `onCreate` to add the option without selecting it, or to save it on your server first and select it once it's there. The row isn't offered at `maxSelected`, and with [server search](#search-on-a-server) it waits for the results and checks their labels.

## Search on a server

Pass `loadOptions` and the picker runs the search for you. It waits for a pause in typing (`searchDebounce`, 300 ms by default), shows the loader from the keystroke until the results arrive, and ignores answers to older queries. Before the user types, it lists `options`; with none, like here, it shows `searchPrompt` (default *Type to search*). A search with no results shows `emptyText`.

```tsx live
import { useState } from 'react';
import { SelectPicker } from '@elik56a/react-native-pickers';

const CITIES = ['Amsterdam', 'Athens', 'Barcelona', 'Berlin', 'Lisbon', 'London', 'Madrid', 'Milan', 'Paris', 'Prague', 'Rome', 'Vienna'];

// Stands in for your API
const searchCities = (query: string) =>
  new Promise<{ label: string; value: string }[]>((resolve) =>
    setTimeout(
      () =>
        resolve(
          CITIES.filter((c) => c.toLowerCase().includes(query.toLowerCase())).map((c) => ({
            label: c,
            value: c,
          }))
        ),
      700
    )
  );

export default function Example() {
  const [city, setCity] = useState<string | null>(null);
  return (
    <SelectPicker
      label="City"
      placeholder="Search a city"
      value={city}
      onChange={setCity}
      loadOptions={searchCities}
      searchPrompt="Type a city"
      emptyText="No city matches"
    />
  );
}
```

- **Search field from the start**, even with no `options`.
- **No double filtering**: results are listed as `loadOptions` returns them. Pass `filterOption` to filter anyway.
- **The selected label stays** in the field after a new search drops it from the results.
- **A failed request** shows `emptyText`.

For a whole form built this way, see the [flight search form recipe](../recipes/flight-search-form).

### Searching yourself

For full control (pagination, caching, your own state), use `onSearchChange` instead: it's called with the query once typing pauses, and you set `options` and `loading`. With options showing, `loading` puts the spinner under them, which suits `onEndReached` for loading the next page. See the [Search a server recipe](../recipes/server-search).

`renderLoading` replaces the spinner and text with your own element:

```tsx
<SelectPicker
  // …
  loading={loading}
  renderLoading={(theme) => <Text style={{ color: theme.colors.textSecondary }}>Asking the server…</Text>}
/>
```

## Clearing

`clearable` shows a × in the field when something is selected.

- In **multiple** mode, × calls `onChange([], [])` and then `onClear`.
- In **single** mode, × calls **only** `onClear`. Reset your state there:

```tsx live
import { useState } from 'react';
import { SelectPicker } from '@elik56a/react-native-pickers';

export default function Example() {
  const [v, setV] = useState<string | null>('b');
  return (
    <SelectPicker
      label="Priority"
      clearable
      onClear={() => setV(null)}
      options={[
        { label: 'Low', value: 'a' },
        { label: 'Medium', value: 'b' },
        { label: 'High', value: 'c', description: 'Pages on-call' },
      ]}
      value={v}
      onChange={setV}
    />
  );
}
```

## Errors and helper text

`error` shows the field as invalid: a red border and label, and the message under the field when it's a string. `helperText` is the line under the field while there's no error message, and `required` adds an asterisk to the label. Your form decides what's invalid; see [Forms](../guides/forms).

```tsx live
import { useState } from 'react';
import { SelectPicker } from '@elik56a/react-native-pickers';

export default function Example() {
  const [tags, setTags] = useState<string[]>([]);
  return (
    <SelectPicker
      label="Tags"
      multiple
      required
      helperText="Up to 3"
      error={tags.length === 0 && 'Pick at least one tag'}
      maxSelected={3}
      options={['Bug', 'Feature', 'Docs', 'Design'].map((t) => ({ label: t, value: t }))}
      value={tags}
      onChange={setTags}
    />
  );
}
```

## Closing behaviour

In single mode, the value changes as soon as an option is tapped and the sheet or dropdown closes (`closeOnSelect`, default `true`); the row's ripple finishes while it animates out. With `closeOnSelect={false}` a sheet or modal stays open and shows a **Done** button. In a sheet or modal, multiple mode always shows Done. A dropdown has no Done button: a tap outside closes it, and a second tap on the field folds an inline list. `onOpen` and `onClose` fire when the list opens and closes.

## Hover and ripple

Rows tint while the pointer is over them and ripple from the touch point when picked; in single mode the ripple finishes as the list closes. The field tints on hover but doesn't ripple. Both colours come from the theme, so a brand tint is one prop:

```tsx live
import { useState } from 'react';
import { SelectPicker } from '@elik56a/react-native-pickers';

const frameworks = [
  'Expo',
  'React Native CLI',
  'React Native Web',
  'Next.js',
  'Remix',
  'Vite',
].map((f) => ({ label: f, value: f }));

export default function Example() {
  const [framework, setFramework] = useState<string | null>(null);
  return (
    <SelectPicker
      label="Framework"
      placeholder="Choose a framework"
      options={frameworks}
      value={framework}
      onChange={setFramework}
      theme={{
        colors: {
          hover: 'rgba(200,70,13,0.08)',
          ripple: 'rgba(200,70,13,0.24)',
        },
      }}
    />
  );
}
```

See [Theming → Hover and ripple](../guides/theming#hover-and-ripple) to change them everywhere or turn them off.

## Custom trigger

`renderTrigger` replaces the field. Call `open()` to show the sheet:

```tsx live
import { useState } from 'react';
import { Pressable, Text } from 'react-native';
import { SelectPicker } from '@elik56a/react-native-pickers';

const sorts = [
  { label: 'Most relevant', value: 'relevance' },
  { label: 'Newest first', value: 'newest' },
  { label: 'Price: low to high', value: 'price_asc' },
  { label: 'Price: high to low', value: 'price_desc' },
];

export default function Example() {
  const [sort, setSort] = useState<string | null>('relevance');
  return (
    <SelectPicker
      options={sorts}
      value={sort}
      onChange={setSort}
      sheetTitle="Sort by"
      renderTrigger={({ open, selected }) => (
        <Pressable
          onPress={open}
          style={{
            alignSelf: 'flex-start',
            paddingVertical: 8,
            paddingHorizontal: 14,
            borderRadius: 999,
            backgroundColor: '#EEF2FF',
          }}
        >
          <Text style={{ color: '#C8460D', fontWeight: '600' }}>
            ↕ {selected[0]?.label ?? 'Sort'}
          </Text>
        </Pressable>
      )}
    />
  );
}
```

The field's chevron rotates when it opens and closes. `renderChevron` swaps the icon and keeps the rotation, so any icon works, an SVG included:

## Custom options

`renderOption` replaces each row's content (taps, selection background and accessibility are still handled). `renderGroupHeader` replaces section headers.

```tsx live
import { useState } from 'react';
import { View, Text } from 'react-native';
import { SelectPicker } from '@elik56a/react-native-pickers';

const people = [
  {
    label: 'Ada Lovelace',
    value: 'ada',
    description: 'Mathematician',
    color: '#F59E0B',
  },
  {
    label: 'Alan Turing',
    value: 'alan',
    description: 'Computer scientist',
    color: '#10B981',
  },
  {
    label: 'Grace Hopper',
    value: 'grace',
    description: 'Rear admiral',
    color: '#6366F1',
  },
];

export default function Example() {
  const [who, setWho] = useState<string | null>(null);
  return (
    <SelectPicker
      label="Assignee"
      options={people}
      value={who}
      onChange={setWho}
      renderOption={({ option, selected, theme }) => {
        const p = people.find((x) => x.value === option.value)!;
        return (
          <View
            style={{
              flexDirection: 'row',
              alignItems: 'center',
              gap: 12,
              flex: 1,
            }}
          >
            <View
              style={{
                width: 36,
                height: 36,
                borderRadius: 18,
                backgroundColor: p.color,
                alignItems: 'center',
                justifyContent: 'center',
              }}
            >
              <Text style={{ color: 'white', fontWeight: '700' }}>
                {p.label[0]}
              </Text>
            </View>
            <View style={{ flex: 1 }}>
              <Text
                style={{
                  color: theme.colors.text,
                  fontWeight: selected ? '700' : '500',
                }}
              >
                {p.label}
              </Text>
              <Text style={{ color: theme.colors.textSecondary, fontSize: 12 }}>
                {p.description}
              </Text>
            </View>
            {selected && <Text style={{ color: theme.colors.primary }}>●</Text>}
          </View>
        );
      }}
    />
  );
}
```

## Presentation

`presentation` picks how the options open:

- `'auto'` (default): a dropdown on the web, a bottom sheet on native.
- `'bottomSheet'`: always a bottom sheet.
- `'modal'`: always a centered modal.
- `'dropdown'`: a popover under the field, as wide as the field. It flips above the field when there's more room there, and a tap outside closes it.
- `'inline'`: the list expands under the field, pushing the content below it, and folds back up on a second tap or once an option is picked (with `closeOnSelect`). It's at most 320 px tall and scrolls past that.

```tsx live
import { useState } from 'react';
import { SelectPicker } from '@elik56a/react-native-pickers';

export default function Example() {
  const [value, setValue] = useState<string | null>(null);
  return (
    <SelectPicker
      label="Framework"
      value={value}
      onChange={setValue}
      options={['Expo', 'React Native CLI', 'Next.js', 'Vite'].map((label) => ({
        label,
        value: label,
      }))}
    />
  );
}
```

## Sheet options

Customise the sheet through `sheet`, which takes [`PickerSheet`](./picker-sheets#pickersheet) props such as `confirmLabel` and `sheetProps` (passed through to [`BottomSheet`](./bottom-sheet)):

```tsx
<SelectPicker
  options={options}
  value={value}
  onChange={setValue}
  sheetTitle="Choose a city"
  sheet={{ confirmLabel: 'Apply', sheetProps: { height: 0.7, enableSwipeToClose: false } }}
  listHeight={400}
  autoFocusSearch
/>
```

### Expanding the sheet

Long lists open at their content height and can grow to full screen: drag the header up on iOS and Android, or scroll the wheel up over the sheet on the web. The list grows with the sheet. Set the expanded height through `sheet.sheetProps`:

```tsx live
import { useState } from 'react';
import { SelectPicker } from '@elik56a/react-native-pickers';

const countries = [
  'Argentina',
  'Australia',
  'Austria',
  'Belgium',
  'Brazil',
  'Canada',
  'Chile',
  'China',
  'Denmark',
  'Egypt',
  'Finland',
  'France',
  'Germany',
  'Greece',
  'India',
  'Ireland',
  'Israel',
  'Italy',
  'Japan',
  'Mexico',
  'Netherlands',
  'Norway',
  'Poland',
  'Portugal',
  'Spain',
  'Sweden',
  'Switzerland',
  'Turkey',
  'United Kingdom',
  'United States',
].map((c) => ({ label: c, value: c }));

export default function Example() {
  const [country, setCountry] = useState<string | null>(null);
  return (
    <SelectPicker
      label="Country"
      options={countries}
      value={country}
      onChange={setCountry}
      presentation="bottomSheet"
      sheet={{ sheetProps: { expandedHeight: 0.9, draggable: true } }}

  );
}
```

`expandable: false` keeps the sheet at its content height; `draggable: false` turns off dragging on native. See [BottomSheet](./bottom-sheet#expanding-to-full-screen) for all the options.

## Accessibility

The field is a button labelled with `label` (or the placeholder), with the current selection as its hint and an `expanded` state. With `required` its label ends in `, required`, an `error` message follows the selection in the hint, and the line under the field announces an error as it appears. Options are `button`s (single; `radio`s in the Material design) or `checkbox`es (multiple) with `selected` / `checked` / `disabled` states, and chips announce `Remove {label}`.

## Props

### Value

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `options` | `ReadonlyArray<SelectOption<T>>` | `[]` | The options; with `loadOptions`, the ones shown before the user types. |
| `multiple` | `boolean` | `false` | Multi-select mode. |
| `value` | `T \| null` · `T[]` | — | Selected value(s). |
| `onChange` | `(value: T, option: SelectOption<T>) => void` · `(values: T[], options: SelectOption<T>[]) => void` | — | Single · multiple. |
| `maxSelected` | `number` | — | Multiple only: maximum selected options. |
| `isEqual` | `(a: T, b: T) => boolean` | `Object.is` | Value equality. |

### Field

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `string` | — | Label above the field (floating inside it in Material, above a `renderTrigger`); also the default sheet title. |
| `placeholder` | `string` | `'Select…'` | Shown when nothing is selected. |
| `disabled` | `boolean` | `false` | Disable the field. |
| `clearable` | `boolean` | `false` | Show a × button when something is selected. |
| `onClear` | `() => void` | — | Called by ×. In single mode, reset `value` here. |

| `helperText` | `string` | — | Shown under the field, replaced by the `error` message. |
| `required` | `boolean` | `false` | Adds an asterisk to the label and tells screen readers the field is required. The value isn't checked. |
| `chips` | `boolean` | `true` | Multiple: show selections as removable chips. |
| `renderChevron` | `(info: { open, theme }) => ReactNode` | — | Custom chevron icon (an SVG, an icon font…). It still rotates on open and close. |

| `style` | `StyleProp<ViewStyle>` | — | Wrapper style (label + field). |

| --- | --- | --- | --- |

| `onEndReached` | `() => void` | — | Called near the end of the list, to load more. |
| `loading` | `boolean` | `false` | Spinner in place of an empty list, or under the options. |
| `loadingText` | `string` | `'Loading…'` | Text next to the spinner. |
| `renderLoading` | `(theme) => ReactNode` | — | Custom loader. |
| `emptyText` | `string` | `'No results'` | Shown when nothing matches. |
| `onCreate` | `(text: string) => SelectOption<T> \| void` | — | [Offer the typed text as a new option](#create-new-options) when no label matches. Return the option to select it. |
| `createLabel` | `(text: string) => string` | `` (text) => `Add "${text}"` `` | The create row's text. |
| `showCheckmarks` | `boolean` | `true` | Check marks / checkboxes on rows. |
| `renderOption` | `(info: { option, selected, disabled, theme }) => ReactNode` | — | Custom row content. |
| `renderGroupHeader` | `(group: string, theme) => ReactNode` | — | Custom section header. |
| `listHeight` | `number` | grows with content | Fixed list height. |
| `autoFocusSearch` | `boolean` | `false` | Focus search when the sheet opens. |
| `styles` | `SlotStyles<SelectSlot \| SelectTriggerSlot>` | — | Slots for both the field and the list. |
