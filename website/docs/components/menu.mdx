# Menu

`Menu` drops a list of actions from the button that opens it: the ⋯ on a card, a "Sort" button, a toolbar icon. Long-press instead, and it's a context menu. It takes the same `actions` as [`ActionSheet`](./action-sheet), and `presentation="sheet"` opens them as one.

It's pure JavaScript, so unlike native menus it runs in Expo Go and on the web, and looks the same as the rest of your pickers: iOS, Material or web.

```tsx
import { Menu } from '@elik56a/react-native-pickers';
```

```tsx live
import { useState } from 'react';
import { Text, View } from 'react-native';
import { Menu } from '@elik56a/react-native-pickers';

const icon = (emoji) => <Text style={{ fontSize: 16 }}>{emoji}</Text>;

export default function Example() {
  const [pinned, setPinned] = useState(false);
  const [last, setLast] = useState('Nothing yet');
  return (
    <View style={{ flexDirection: 'row', alignItems: 'center', justifyContent: 'space-between' }}>
      <Text>Last action: {last}</Text>
      <Menu
        accessibilityLabel="Note options"
        actions={[
          { label: 'Edit', icon: icon('✏️'), onPress: () => setLast('Edit') },
          { label: 'Duplicate', icon: icon('📄'), onPress: () => setLast('Duplicate') },
          { label: 'Pin to top', icon: icon('📌'), selected: pinned, onPress: () => setPinned((p) => !p) },
          { label: 'Delete', icon: icon('🗑️'), destructive: true, onPress: () => setLast('Delete') },
        ]}
      >
        <Text style={{ fontSize: 22, paddingHorizontal: 12 }}>⋯</Text>
      </Menu>
    </View>
  );
}
```

## Actions

Each action is the same as in an [`ActionSheet`](./action-sheet#actions): `{ label, onPress, description, icon, selected, destructive, disabled, testID }`. A tap closes the menu and `onPress` runs once it has closed, so an action can open a sheet or a modal.

The iOS design puts icons after the label with a hairline between actions, as iOS menus do; Material and the web put them first.

## The trigger

`children` is the trigger. A node is wrapped in a pressable that opens the menu; name it for screen readers with `accessibilityLabel`. To use your own button, pass a function: it gets `open` and `visible`.

This one is a "Sort" button with a title, a ✓ on the current order and a line under each choice:

```tsx live
import { useState } from 'react';
import { Pressable, Text, View } from 'react-native';
import { Menu } from '@elik56a/react-native-pickers';

const SORTS = [
  { label: 'Relevance', description: 'Best match first' },
  { label: 'Price', description: 'Lowest first' },
  { label: 'Rating', description: 'Highest rated first' },
  { label: 'Distance', description: 'Needs your location', disabled: true },
];

export default function Example() {
  const [sort, setSort] = useState('Relevance');
  return (
    <View style={{ alignItems: 'center' }}>
      <Menu
        title="Sort results by"
        actions={SORTS.map((s) => ({ ...s, selected: s.label === sort, onPress: () => setSort(s.label) }))}
      >
        {({ open, visible }) => (
          <Pressable
            onPress={open}
            accessibilityRole="button"
            style={{ flexDirection: 'row', gap: 6, paddingVertical: 8, paddingHorizontal: 14, borderRadius: 999, borderWidth: 1, borderColor: '#E8E4DC' }}
          >
            <Text>Sort: {sort}</Text>
            <Text>{visible ? '▴' : '▾'}</Text>
          </Pressable>
        )}
      </Menu>
    </View>
  );
}
```

## Context menu

`openOnLongPress` opens the menu on a long press instead of a tap, as a message bubble or a photo does.

```tsx live
import { Text, View } from 'react-native';
import { Menu } from '@elik56a/react-native-pickers';

export default function Example() {
  return (
    <View style={{ alignItems: 'center' }}>
      <Menu
        openOnLongPress
        accessibilityLabel="Message, long-press for options"
        actions={[
          { label: 'Reply' },
          { label: 'Copy' },
          { label: 'Forward', description: 'To a chat or a group' },
          { label: 'Delete', destructive: true },
        ]}
      >
        <View style={{ backgroundColor: '#F4F2EE', padding: 12, borderRadius: 16 }}>
          <Text>Long-press me 👋</Text>
        </View>
      </Menu>
    </View>
  );
}
```

## Where it opens

The menu opens under the trigger, or above it when there's more room there. `align` picks the edge it lines up with:

- `'auto'` (default): the trigger's left edge, or its right edge when the trigger sits in the right half of the window, so a ⋯ at the end of a row opens inwards.
- `'start'` / `'end'`: the trigger's start or end edge, flipped in right-to-left layouts.

`width` sets the menu's width: 250 in the iOS design and 200 otherwise.

`presentation="sheet"` opens the same actions as an [`ActionSheet`](./action-sheet) instead, from the bottom of the screen.

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `actions` | `MenuAction[]` | **required** | The actions, top to bottom. Same shape as [`ActionSheetAction`](./action-sheet#props). |
| `children` | `ReactNode \| ({ open, visible }) => ReactNode` | **required** | The trigger: a node that opens the menu, or a function for your own button. |
| `title` | `string` | — | A small heading above the actions. |
| `align` | `'auto' \| 'start' \| 'end'` | `'auto'` | The trigger edge the menu lines up with. |
| `width` | `number` | `250` iOS / `200` other | The menu's width. |
| `presentation` | `'menu' \| 'sheet'` | `'menu'` | A menu by the trigger, or an action sheet. |
| `openOnLongPress` | `boolean` | `false` | Open on a long press, as a context menu. |
| `disabled` | `boolean` | `false` | The trigger doesn't open the menu. |
| `onOpen` / `onClose` | `() => void` | — | When it opens; when it closes for any reason, before an action runs. |
| `accessibilityLabel` | `string` | — | What screen readers call the trigger, such as 'More options'. |
| `theme` / `design` | | | See [Theming](../guides/theming) and [Designs](../guides/designs). |
| `style` | `ViewStyle` | — | The box around the trigger. |
| `styles` | `{ trigger, menu, header, title, action, actionLabel, actionDescription, check }` | — | [Slot styles](../guides/styling). |
| `testID` | `string` | — | On the trigger; the menu gets `${testID}-menu`. |

## Accessibility

The trigger is a button that reports whether the menu is expanded. Each action is a button named by its label and description, marked disabled or selected. A tap outside, Android's Back and Escape on the web close the menu, and on the web arrow keys move between actions.
